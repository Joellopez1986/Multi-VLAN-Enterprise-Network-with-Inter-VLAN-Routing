# Multi-VLAN-Enterprise-Network-with-Inter-VLAN-Routing
A simulated enterprise network built in Cisco Packet Tracer, segmenting 12 end devices, a server, and a laptop into five department-based VLANs (Admin, Finance, IT, Management, Servers) with inter-VLAN routing configured on a Layer 3 switch and a routed uplink to an edge router.
